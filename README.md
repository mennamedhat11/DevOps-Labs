# DevOps-Labs

Hands-on DevOps labs: build tools, Docker, Kubernetes, Jenkins, ArgoCD, and Ansible.

## Structure

```
DevOps-Labs
├── Build Tools
│   ├── Lab1   # Maven
│   └── Lab2   # Gradle
└── Docker
    ├── Lab 3-part1:   # Docker image: build inside Docker
    └── Lab 3-part2:   # Docker image: build locally
```

## Labs

- **Lab 1:** Building and packaging a Java application with Maven
- **Lab 2:** Building and packaging a Java application with Gradle
- **Lab 3-part1:** Docker image for a Java application, built inside Docker
- **Lab 3-part2:** Docker image for a Java application, built locally, plus an image size comparison
